# Шашки

## Запуск

```bash
python -m pip install pygame-ce
python main.py
```

## Файли

- `board.py` - правила гри: генерація ходів, виконання ходу, кінець партії
- `checkers.py` - бот
- `main.py` - вікно, малювання, кнопки

## Правила

- взяття обов'язкове, і серію взять треба довести до кінця
- шашка б'є і вперед, і назад
- дамка ходить і б'є по діагоналі на будь-яку відстань
- шашка, яка дійшла до останнього ряду, стає дамкою
- якщо 40 ходів поспіль не було ні взяття, ні ходу простої шашки, то в грі з людиною буде нічия
- у режимі «бот проти бота» нічиї немає: у такому випадку перемагає той, у кого більше (далі порівнюються дамки, просування шашок і кількість ходів), а при повній рівності переможець випадковий

## Бот

Бот шукає хід алгоритмом Negamax з альфа-бета відсіканням. Пошук ітеративний: спочатку глибина 1, потім 2 і так до заданої глибини або поки не вийде `time_limit`. Ходи, де б'ється більше шашок, перебираються першими. Коли глибина закінчилась, а в позиції є взяття, пошук продовжується ще на крок (не більше `MAX_EXT` разів), щоб не оцінювати позицію посеред розміну.

Щоб бот не ходив туди-сюди, позиції, що вже були, штрафуються (`REP_PENALTY`). Параметр `noise` дозволяє вибирати випадково серед ходів з майже однаковою оцінкою.

Три рівні складності задані в `LEVELS` у `main.py` (глибина, ліміт часу, шум).
